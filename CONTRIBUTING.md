# How to contribute

### Did you find a bug?

- Please open an issue in the tracker from GitHub: [github.com/damoc1es/vertigoes-mod/issues](https://github.com/damoc1es/vertigoes-mod/issues).

### Do you want to fix something?

- At this moment, this repository does not accept any contribution from people other than the owner and possibly personally approved people. Subject to change.

# How is the project structured

- Main branch is `main` and releases are set as tags.
- Commits are following [conventional commits](https://www.conventionalcommits.org/en/v1.0.0/#summary). Or, at least, trying to.
- Releases are following [semantic versioning](https://semver.org), with the addition of the Minecraft version that it's made for: `X.Y-MAJOR.MINOR.PATCH` where `X.Y` is the Minecraft version (without the leading `1.`, where it's the case).
